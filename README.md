# RED LINE FISHING v1 — نسخة أولى قابلة للتعديل

هذه الحزمة هي بداية مستقلة وليست نسخة مطابقة لملفات الموقع المنشور. تم إعدادها لتبدأ التطوير بسرعة:
- خريطة Leaflet + OpenStreetMap
- طقس ورياح عبر Open-Meteo
- عرض مبسط للأمواج
- أماكن صيد تجريبية
- العربية / الفرنسية
- واجهة داكنة قابلة للتطوير

## التشغيل
لا تحتاج Node.js. افتح `index.html` في المتصفح، أو ارفع المجلد كما هو إلى GitHub Pages / Netlify.

## الرفع المجاني — GitHub Pages
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع الملفات الموجودة داخل هذا المجلد.
3. Settings → Pages.
4. اختر Deploy from a branch.
5. اختر `main` و`/ (root)` ثم Save.
6. انتظر حتى يظهر رابط الموقع.

## ما تمت إضافته في v4
- طبقة رياح مرئية متحركة فوق الخريطة.
- جسيمات تتحرك حسب اتجاه الرياح من Open-Meteo.
- إعادة أخذ عينات للرياح عند تحريك/تكبير الخريطة.
